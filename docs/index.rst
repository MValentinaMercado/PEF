Referencia del código
=====================

Esta es la documentación **interna** del proyecto: módulos, clases y
funciones, generados a partir de los *docstrings* con Sphinx. Los ejemplos
``>>>`` de los docstrings se ejecutan como pruebas, así que esta referencia
no se desactualiza en silencio.

La documentación **externa** (qué hace el sistema, cómo se instala y se usa,
arquitectura, decisiones, API, pruebas, seguridad y mantenimiento) está
escrita con MkDocs en ``documentacion/`` y se publica en la raíz del mismo
sitio.
