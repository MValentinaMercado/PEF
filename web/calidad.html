Análisis de calidad del código

Se utiliza Ruff como herramienta de análisis estático: detecta errores probables, imports sin usar, código demasiado complejo y problemas de estilo sin ejecutar el programa. También se mide la cobertura de las pruebas con pytest-cov. Las condiciones de calidad son que si alguna no se cumple, el pipeline falla.
