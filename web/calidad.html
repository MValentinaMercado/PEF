Análisis de calidad con SonarQube

SonarQube Cloud analiza el código desde el pipeline de integración continua: detecta bugs, vulnerabilidades, puntos críticos de seguridad, code smells y duplicación, y mide la cobertura. El Quality Gate es el conjunto de condiciones que debe cumplir el código nuevo; con sonar.qualitygate.wait=true el pipeline espera su resultado.

Métricas del proyecto

Cómo está configurado

El proyecto se identifica en sonar-project.properties. El pipeline(.github/workflows/ci.yml) genera coverage.xml con pytest --cov y ejecuta el análisis con la action oficial.

El mismo pipeline ejecuta, en etapas separadas: Gitleaks (secretos); Ruff, mypy, Vulture, Pylint, Radon y Bandit; pytest con cobertura mínima del 80 % junto con SonarQube; pip-audit, MkDocs, Sphinx y Lychee; y, solo si todas aprobaron, los controles de rendimiento y memoria.
